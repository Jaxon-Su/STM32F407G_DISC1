STM32 HAL Example Note
======================

案例：011 I2C Slave TX Long String
來源概念：014i2c_slave_tx_string2.c

核心行為
--------
STM32 作為 I2C slave 0x68，回傳 4-byte 長度與長字串 payload。

硬體設定
--------
PB6/PB7 I2C1 slave

搬移重點
--------
- Driver-layer 的 GPIO alternate function / peripheral clock / IRQ enable，在 HAL 專案裡拆到 MX_*_Init() 和 HAL_*_MspInit()。
- 實際範例邏輯集中在 Core/Src/example_*.c。
- main.c 只負責 HAL、clock、GPIO、外設初始化，然後呼叫 example init/loop。

注意
----
I2C 案例需要外部 slave/master 實際配合。UART 案例需要 USB-UART 或另一塊板子/Arduino 回應。DS1307 案例需要 DS1307 模組與 3.3V-safe I2C pull-up。
