STM32 HAL Example Note
======================

案例：012 UART TX
來源概念：015uart_tx.c

目標
----
這個案例練習最基本的 UART transmit。

按下 `B1 / PA0` 後，STM32 透過 `USART2_TX / PA2` 傳送字串：

```c
"UART Tx testing...\n\r"
```

這個案例使用 polling/blocking transmit：

```c
HAL_UART_Transmit(&huart2, msg, len, 100);
```

也就是 CPU 會等到傳送完成或 timeout。

硬體設定
--------

- `PA2`：USART2_TX
- `PA3`：USART2_RX
- Baud rate：`115200`
- Word length：8-bit
- Stop bit：1
- Parity：None
- Flow control：None
- 常寫成：`115200 8N1`

如果用 USB-UART module：

```text
STM32 PA2 / TX -> USB-UART RX
STM32 PA3 / RX -> USB-UART TX
STM32 GND      -> USB-UART GND
```

只看 TX 時，至少要接：

```text
PA2 -> USB-UART RX
GND -> GND
```

注意 STM32F407 是 3.3V logic。USB-UART 請用 3.3V TTL level，不要用 RS232 +/- voltage。

main.c 的角色
-------------

`main.c` 初始化 UART 與 GPIO：

```c
HAL_Init();
SystemClock_Config();
MX_GPIO_Init();
MX_USART2_UART_Init();
Example012_UartTx_Init();
```

然後 main loop 持續呼叫：

```c
Example012_UartTx_Loop();
```

UART 腳位實際在 `HAL_UART_MspInit()` 中設定：

```c
GPIO_InitStruct.Pin = GPIO_PIN_2 | GPIO_PIN_3;
GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;
GPIO_InitStruct.Pull = GPIO_PULLUP;
GPIO_InitStruct.Alternate = GPIO_AF7_USART2;
```

USART2 clock 也在 MSP init 打開：

```c
__HAL_RCC_USART2_CLK_ENABLE();
```

程式流程
--------

`Example012_UartTx_Loop()`：

```c
if (!WaitButtonPress()) return;

if (HAL_UART_Transmit(&huart2, msg, strlen(msg), 100) == HAL_OK)
{
    HAL_GPIO_TogglePin(LD4_GPIO_Port, LD4_Pin);
}
else
{
    HAL_GPIO_TogglePin(LD5_GPIO_Port, LD5_Pin);
}
```

流程圖：

```text
while loop
  -> WaitButtonPress()
  -> debounce 200ms
  -> 等使用者放開按鈕
  -> HAL_UART_Transmit()
  -> 成功：LD4 toggle
  -> 失敗：LD5 toggle
```

HAL_UART_Transmit 參數
---------------------

```c
HAL_UART_Transmit(&huart2, msg, len, 100);
```

含義：

- `&huart2`：USART2 的 HAL handle，CubeMX 在 `main.c` 建立並初始化。
- `msg`：要送出的 buffer address。
- `len`：要送幾個 byte。
- `100`：timeout，單位 ms。

這個函式是 blocking/polling 版。呼叫後 HAL 會等待 TXE/TC 等 flag，直到資料送完或 timeout。

為什麼 012 沒有 callback
-----------------------

因為 012 使用：

```c
HAL_UART_Transmit()
```

不是：

```c
HAL_UART_Transmit_IT()
HAL_UART_Transmit_DMA()
```

Polling/blocking 版本傳完就從函式返回，所以不需要 callback。

即使專案有 `USART2_IRQHandler()` 和 NVIC enable，這個案例主要不靠中斷完成 TX。那是因為專案模板或後續案例共用 UART interrupt 設定；012 的核心仍是 blocking transmit。

學習重點
--------

UART TX 最重要的是確認：

```text
baud rate / data bits / parity / stop bits
```

兩端一致。

若 PC terminal 看不到字：

- 檢查 TX/RX 是否交叉接。
- 檢查 GND 是否共地。
- 檢查 baud rate 是否 115200。
- 檢查 terminal 是否選對 COM port。
- 檢查 USB-UART 是否為 3.3V TTL。
